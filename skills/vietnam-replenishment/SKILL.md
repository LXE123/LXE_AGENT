# 越南备货清单

## 选择执行路径

- **完整备货任务，未指定 ERP 报表**：直接读取 `yacang-reports-export`，导出 VN8806 库存动销、当前库存及全局产品资料，再执行计算。无需先读总 Map 或寻找历史文件。
- **用户指定完整三份报表，或同一任务已成功导出**：使用这些文件，不重复采集。同一任务重算时复用已确认的报表；用户明确要求更新数据时才重新导出。
- **只指定部分报表、要求仅计算但缺输入，或来源范围不明确**：先澄清缺失文件或取数范围，不擅自混用新旧数据。明确指定的文件无效时报告实际错误，不改用历史文件。
- 默认不搜索 Downloads、历史导出目录或按文件修改时间挑选数据。只有用户明确要求查找历史文件时，才在其指定范围内查找。
- 本轮上传的完整九表模板直接使用附件提供的真实路径；全局参数由计算脚本自动读取，无需预先查询。裸上传但目的不明确时先澄清。
- 查询已有备货结果时读取对应产物；无法确定是哪份时先确认。仅询问流程、参数或能力时回答问题，不启动导出或计算命令。明确只要原始报表时直接使用 `yacang-reports-export`。

## 输入与设置

- 九表模板的「越南备货清单」提供本轮 SKU 的热销标记、成本、跨境价和折扣价，不需要上传独立 SKU 映射表。每个匹配的 SKU 必须填写热销标记，只能为 `1` 或 `2`，用于确定备货天数。成本、跨境价和折扣价可分别留空，填写时必须大于 `0`；缺少金额只让依赖该字段的价格、利润结果留空，不影响备货数量。业务人员负责提供真实数值，AI 不得猜测、填零或用默认标记补齐。
- 全局参数包括 7、15、30 天销量权重、各周期天数修正及人民币兑越南盾汇率。日均销量 = 周期销量 ÷（天数 + 修正值），再按销量权重合并。汇率表示 1 元人民币对应多少越南盾。
- 全局参数和长期九表模板由用户在「工作台 → 越南备货设置」中维护，当前桌面应用的工作目录共用。首次在设置页上传完整模板，后续运行直接复用已保存的当前模板；设置页可导出当前模板。参数保存在 `$LXE_DATA_ROOT/skill-data/vietnam-stock-recommendation/parameters.json`，模板保存在应用输入资产槽，不保存在技能源码目录。
- 脚本自动读取参数，生成前无需查询或把数值填进命令。只在用户询问当前参数时，通过普通 `exec` 读取 `LXE_DATA_ROOT` 环境变量的路径，再用 `read` 读取对应 `parameters.json`。Unix 可执行 `printenv LXE_DATA_ROOT`；Windows PowerShell 可读取 `$env:LXE_DATA_ROOT`。不要把所有环境变量或包含凭据的设置文件输出给用户，也不要猜应用目录。参数文件使用十进制字符串，`sales_weight_*` 是比例（展示给用户时乘以 100%），`day_adjustment_*` 是天数修正。
- 参数临时覆盖暂不支持；用户要求其他值时提示先在桌面设置保存，不能忽略要求后使用旧值生成，也不要直接编辑参数文件。
- ERP 提供 VN8806 的 SKU、名称、7/15/30 天销量、可用库存、在途数量、上架时间。上架时间取仓库产品的“创建时间”，在途取本轮当前库存列表。计算用五表骨架内置；最终九表输出还需完整业务模板。省略 `--template-file` 时，必须已有设置页保存的当前模板；聊天中提供的模板不会保存为当前模板。

| 命令参数 | 输入报表 | 主要字段 |
|---|---|---|
| `--sales-file` | VN8806 库存动销（`inventory-sales`） | SKU、7/15/30 天销量 |
| `--inventory-file` | VN8806 当前库存（`inventory`） | SKU、可用库存、在途数量 |
| `--products-file` | 全局仓库产品资料（`products`） | SKU、中文标题、创建时间 |

三份报表均为必填路径。计算只读取本地文件，不登录 ERP、不下载数据，也不会在输入缺失或无效时自动导出。报表和九表模板在读取前复制为本轮快照；全局参数固定为本轮输入。

完整业务模板必须按顺序包含「越南备货清单、改库存、改折扣、报官方活动、竞价报名、雅仓库存、雅仓动销、数据更改、库存商品信息」九张表。提供模板路径时，使用 `--template-file "/实际路径/东南亚越南备货清单.xlsx"`，只用于本次计算；不提供时使用已保存的当前模板。缺少模板时按命令提示请用户在设置页上传，不能用五表结果冒充完整清单。只有设置页上传会替换长期当前版。本轮计算会固定模板副本，原始文件不改。

模板仅支持 Excel 1900 日期系统。1904 模板或模板与计算结果日期系统不一致时停止，不自动转换日期，也不修改工作簿的日期系统标志。

库存动销接受去掉末列“创建日期”的交付表，也接受用户已有的含该列原件；该列不参与备货计算，上架时间仍取仓库产品资料的“创建时间”。

## 获取数据（独立步骤）

按上述执行路径确定需要取数后，读取 `yacang-reports-export`，执行：

```sh
lxeskill yacang reports export --report inventory-sales --report inventory --report products --warehouse VN8806
```

- 按导出结果 `data.artifacts` 中的 `report`、`warehouse` 选择三份真实路径。两份库存报表必须来自 VN8806，产品资料为全局；不筛选创建日期。沿用导出 Skill 的认证、权限、等待与失败处理。
- 文件内容可以校验表头、仓库、SKU 和数值，但仅凭路径无法证明同批次、未筛选或数据新鲜度。已有文件范围不明确时先澄清；不要把本次计算时间或文件修改时间声称为 ERP 数据更新时间。
- 导出和计算可以分别调用。只要求导出就到此交付；完整备货任务中将导出结果作为计算输入，不自动发送中间报表。计算失败保留已导出的文件，修正问题后可以复用这些路径，不重新触发采集。

## 执行

通过已有 `exec` 工具执行计算命令，三份路径来自用户提供的文件或导出结果。设置页已上传模板时，可省略下例的 `--template-file`：

```sh
lxeskill vietnam replenishment calculate --sales-file "/实际路径/库存动销.xlsx" --inventory-file "/实际路径/当前库存.xlsx" --products-file "/实际路径/商品资料.xlsx" --template-file "/实际路径/完整九表模板.xlsx"
```

- 多个候选文件无法确定时先请用户选择；不要猜路径或搜索会话数据库。显式指定的模板无效时停止，不改用保存的旧版。
- 从九表模板「越南备货清单」按本轮 SKU 提取热销标记、成本、跨境价和折扣价。跨境价公式使用模板已保存的计算结果，缺少结果或同一 SKU 参数冲突时报错。
- 命令接受必填 `--sales-file`、`--inventory-file`、`--products-file`，以及可选 `--template-file`。不使用 `uv`、`python -m`、shell 拼接或环境变量覆盖包装它。用 `exec.cwd` 设置工作目录，文件路径优先使用绝对路径。
- 遵守现有执行权限模式。若真实错误表明需要访问工作目录之外的输入文件或应用数据（例如参数、锁、日志），通过 `exec` 的 `sandbox_permissions` 与 `justification` 申请本次所需权限。向用户解释实际原因；不自动改整个会话权限。审批拒绝后停止。
- 若 `exec` 返回运行中的任务，使用同一任务的 `wait` 等待完成，不重复启动生成。收到普通业务失败时报告实际脱敏错误，不自动重跑整轮。

## 产出文件说明

最终产出为 `越南备货清单.xlsx`，包含九张工作表，顺序与完整模板一致：

- **越南备货清单**：按 SKU 展示备货或清货判定、建议备货数量及价格利润；H 列当前表头「陆运」就是建议备货数量，需结合判定阅读，不能把空白当作零。
- **雅仓库存、雅仓动销、库存商品信息**：分别保存本轮参与计算的库存与在途、销量、商品名称与上架时间等来源数据，供复核。
- **数据更改**：保存本轮实际使用的销量权重、天数修正和汇率。
- **改库存、改折扣、报官方活动、竞价报名**：完整保留业务模板里的单元格、公式、样式与原有数据。程序不直接改写这四张表；在 Excel 中打开时，依赖其他工作表的公式可按 Excel 的自动计算设置重新计算。

文件保留公式，已由 LibreOffice 重算、保存计算结果并通过校验，可直接预览；用户在 Excel 中修改输入后仍可重算。AI 交付或解释结果时无需再次重算。命令返回的 JSON 是路径、参数和校验摘要，不含每个 SKU 的备货数量；用户追问具体 SKU 时，读取本轮 XLSX 中已保存的结果，不凭摘要推测。

## 结果与交付

- 检查终端 JSON 的 `ok`、`data.success`、`data.status`、`data.validation.status`、`data.output_xlsx` 和 `files`。只有成功完成、校验为 `passed`、最终 XLSX 存在且 `files` 恰好包含该文件时，才调用 `send_files` 发送。不要只凭进程启动或退出码宣称成功。
- 参数错误、文件缺失、坏表、ERP 缺必要来源或重算失败时，转述 `data.error.message` 或 `error.message` 的实际脱敏诊断，不发送旧文件、原始报表或中间工作簿。
- 缺少保存的九表模板时，提示到设置页上传，或为本轮提供文件路径。模板可以缺少部分或全部 ERP SKU：这些 SKU 仍保留雅仓来源数据，热销标记、成本、跨境价、折扣价以及依赖它们的结果留空，不填零，也不因未覆盖全部 ERP SKU 拒绝交付。已有模板行的金额留空可继续计算；非空金额不合法、热销标记缺失或非法时停止并报告实际错误。
- 模板表头、SKU 或数值无效时报告实际错误，不跳过坏行、不自动补值，也不反复运行来逐个发现错误。
- 附件发送成功后再说已交付。结果中的 `data.config`、`data.config_source` 和 `data.template_source` 记录本轮实际输入，必要时用于解释。若发送失败，仅重试发送同一文件，不重新计算。
- `data.source_files` 记录三份报表的类型、原始路径和本轮快照 SHA-256；`data.validation` 记录通过的检查、工作表、SKU 数、缺少模板参数行的 SKU 数及两表在途差异数。缺少模板参数行时保留雅仓数据，其余依赖参数的列留空；在途有差异时仍取当前库存的 `在途数量`。这些计数非零时说明其影响，不将它们误报为全量结果齐全。
