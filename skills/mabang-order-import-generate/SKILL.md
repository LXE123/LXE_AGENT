# 马帮订单导入表生成

使用本轮提供的备货 `.xlsx` 文件和用户指定国家，通过统一命令生成订单导入文件。备货表的 SKU 表头为 `SKU`，SKU 内容为文本。马帮模板随 lxeskillCLI 提供，用户只需提供备货表。本 Skill 负责在本地生成文件，马帮系统中的实际导入由用户完成。

## 调用

根据用户要求和备货表信息确定国家；无法明确确定时再询问。使用附件保存后的真实绝对路径调用命令，将 `--country` 设置为下表中的国家参数：

```bash
lxeskill mabang order-import generate --country indonesia --input-xlsx "/实际路径/印尼备货清单.xlsx"
```

## 国家规则

五国都使用用户提供的备货表和 lxeskillCLI 随包提供的马帮模板。按生成时的北京时间判断最近日期并解释日期表头的年份；每份订单编号使用该文件选中列的日期。

| 国家 | 国家参数 | 来源表与 SKU 列 | 订单前缀 |
|---|---|---|---|
| 巴西 | `brazil` | 「巴西」工作表，F 列为 SKU。 | `BR` |
| 马来西亚 | `malaysia` | 「马来西亚」工作表，E 列为 SKU。 | `MY` |
| 越南 | `vietnam` | 「越南备货清单」工作表，E 列为 SKU。 | `VN` |
| 菲律宾 | `philippines` | 「菲律宾备货清单」工作表，E 列为 SKU。 | `PH` |
| 印尼 | `indonesia` | 「印尼」工作表，E 列为 SKU。 | `IN` |

五国均扫描第 1 行 `M/D` + 可选单个英文字母批次 + `陆运`、`空运` 或 `海运` 表头，巴西不限制在 AT:BD。每种运输方式分别选离生成当天最近的日期，取该日期的全部普通列和批次列；距离相同的不同批次均保留。其他日期的标黄表头也会纳入对应批次。日期可以不同，也可以晚于生成日；可以只有一种运输方式。

同一运输方式和批次如果有多个日期，取该批次离当天最近的列，即使较近列未标黄；距离相同时取较晚日期。同一列被日期和黄标同时选中时只生成一份。黄标按单元格实心标准黄色 `#FFFF00` 识别，包括调色板指向相同颜色的索引；当前不判断其他黄色色阶、主题色或条件格式。没有有效运输列时命令报错；同一方式和批次在选定日期出现重复列时，按下文处理。

未选中的旧列即使年份不明确，也不影响导出；最终选中的列表头年份无法确定时，命令会报错并指出表头，需用户确认。

每个所选运输方式与批次生成一份。订单号是 `{国家前缀}{YYMMDD}[批次]-L`（陆运）、`-K`（空运）或 `-H`（海运），无批次时省略字母。例如 `IN261105C-H`；文件名为 `{国家名}马帮订单导入模板-{订单号}.xlsx`。

数量处理：每份文件只保留所选运输列中数量大于 0 的非空 SKU 行，保留原顺序和重复项；该列数量为 0 或空值的行不导出。其他字段沿用模板默认值，商品单价为 `0`。SKU 及所选数量公式须有缓存结果，已计算得到空字符串时按空值处理；单元格错误、无缓存公式、非法数量或超出可保存精度的数值会使整单失败并报告实际单元格。如果选中列没有任何有效数量，对应文件只有表头。

## 重复列处理

同一运输方式和批次在选定日期有重复列且未指定候选列时，命令会报错并列出候选列。巴西或越南可请用户选择候选列，再使用 `--shipping-column <Excel列字母>` 指定，例如 `AT`。

菲律宾普通空运、A 海运或 B 海运分别使用 `--air-shipping-column`、`--sea-a-shipping-column`、`--sea-b-shipping-column` 指定候选列；可同时使用多个参数。菲律宾其他批次及马来西亚、印尼的重复列需要修正源表。

这些参数也可确认没有重复的候选列；所选列必须属于已选运输方式和批次中离当天最近的日期，菲律宾按方式参数还须匹配对应批次。指定一列后，其他运输方式和批次仍按规则生成。

## 交付

检查终端 JSON 的 `ok`、`data.success`、`data.status`、`data.artifacts` 和 `files`。只有生成成功并校验通过后，才交付 `files` 中的文件；文件数由最近日期和黄标识别出的批次决定。各文件的 `sku_count` 可能不同，应分别查看 `artifacts`；顶层 `data.sku_count` 为第一份文件的行数。成功时说明订单编号和所选运输日期；失败时转述实际诊断，不交付旧文件或不完整结果。
