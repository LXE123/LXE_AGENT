# 报表与字段参考

完整 terminal 外层使用 `type="result"`、`ok`、`data`、`files`。以下只列 `data` 中影响判断的字段：成功有 source_data_time、template_name、template_version、row_count、link_count、各建议分类数量、report_xlsx_path、unlinked_shipments_snapshot_path；缺货件兼容试算有 unlinked_shipments_snapshot_warning。失败读取外层 error.message，data.exception 仅为业务诊断，不能替代外层 ok。

- 结果文件包含 3 个业务 sheet：`最终备货意见`、`本轮不备货`、`链接备货汇总`，另有隐藏的 `源数据核验信息`；不再输出 `备货公式参数`。
- 发货记录统一展示在 `最终备货意见`，不再单独输出 `空运（急发）`、`空运`、`海运`三个 Sheet；运输分类和数量计算不变。
- 简化表的空运、海运建议量已经扣减马帮 FBA 库存及本次取得的未关联货件，不要再次扣减。海运同时需要空运时，两列分别展示最终数量，运输方式为 `空运＋海运`；预计总重量包含两者，单件重量缺失时留空并注明。
- 简化表支持 Excel 公式试算：修改浅黄色的销量、库存、未发出货件总计、补货天数和重量，蓝色公式列自动重算。`未发出货件总计`就是本次取得的未关联货件数量，未取得快照时表内会注明需核实。
- FBA 总库存只合计可售、待入库、预留、在途、待调仓、调仓中；计划入库仅展示，不扣减。90 天销量仅展示，加权日销仍使用本轮参数方案的 7/14/30 天权重。
- 手动修改仅影响简化表；运输方式固定为生成时结果，天数可手改，但不自动重新匹配分档。其他分类表及链接汇总是生成时快照。数量变为零时该行仍保留，排序使用表头筛选，公式只引用本行，使用普通筛选区域，单行修改公式不会触发表格计算列整列自动填充。
- 深圳可用库存不足时仍保留算法建议量，在试算提示中显示缺口；简化表不代表已按深圳库存分配或实际发货。品名优先使用本地 SKU 名称，商品备注保留在可编辑的“备注”列，动态校验和缺口说明位于“输入检查”“试算提示”。没有建议发货记录时只保留表头。
- 返回的 `original_row_count`、`binding_verified_row_count`、`binding_unverified_row_count` 描述源表范围；`row_count` 仍表示实际生成建议的行数。
- 链接备货汇总只累计生成时最终建议发货的数量：总补货量＝空运（急发）补货量＋空运补货量＋海运建议量。空运补货量包含海运记录中的最终同时空运量；清货、样本不足、暂不建议发货不贡献这些数量。其他链接统计保持原有范围，没有发货建议的已有分组仍保留，四个数量列为零。
- 链接备货汇总也是生成时快照，不随首张试算表的手动修改联动；查看原始发货计划可与生成时的最终备货意见对账。

- `本轮不备货`合并原“暂不建议发货”和“样本不足”，保留完整商品粒度及四段销量、实际日销、覆盖天数、库存和未关联数量；通过“未备货原因分类”和“具体原因”复查低销量、库存已覆盖、未达海运门槛等判断。按日销降序排列，不展示容易误认为发货量的中间数量。零日销的覆盖天数留空，负库存与缺失保持原义。本页是生成时快照，原清货记录也并入本页，原因分类为“清货”。
- CLI 的 `no_ship_count`、`sample_insufficient_count`仍分别统计，与 `clearance_count` 三项合计等于“本轮不备货”行数。原因直接来自实际判断分支与生效参数；未达海运日销门槛、件数不足、海运未启用和缺少天数分档分别说明，不统一解释成库存充足。

- 首张表新增“深圳库存缺口”公式列，等于空运与海运建议量合计减去深圳可用库存，最低为0。数值负库存按原值参与计算；库存未知或试算输入非法时缺口留空并在试算提示中显示原因。可筛选缺口大于0的记录，原“真实库存（深圳仓库）不足”页不再输出。
- 清货只合并原本被清货规则排除的记录，不扩大为全部带清货备注的商品；具体原因说明“商品备注含‘清货’，本轮不安排备货”。原“清货”页不再输出，计算分类及链接汇总范围不变。

## 本行分步试算

首张表在补货天数后依次展示“理论空运需求”“理论海运需求”“扣FBA后空运量”“扣FBA后海运量”“扣未关联货件后空运量”“扣未关联货件后海运量”，再展示最终空运、海运建议量。最后的“输入检查”和“试算提示”用于发现空值、非法输入、海运最低件数不足及缺库存／缺重量。

- 所有公式直接引用本行 A1 单元格，不使用跨 Sheet、INDEX/MATCH、隐藏编号或命名参数。加权日销直接写入该商品实际生效的三个权重，海运最低件数直接写在两列最终建议量公式中；手动改变最低件数时，两列须一致调整。
- 海运天数是含空运覆盖期的总目标：理论海运需求＝向上取整（日销×海运天数）−理论空运需求，最低为0。FBA先扣空运，剩余再扣海运；未关联货件按相同顺序继续扣减。每一步保留原有取整，不能把中间量再扣一次当作最终量。
- 第3行示例：理论空运 `=IF(AI3="正常",ROUNDUP(I3*U3,0),"")`；扣未关联货件后空运 `=IF(AI3="正常",MAX(0,ROUNDUP(Y3-R3,0)),"")`。`AI3` 是本行可见“输入检查”。
- 备注为普通文字，可直接修改。未取得快照的说明保留在试算提示；重量仅用于物流参考，不限制海运数量。其余两张业务 Sheet 仍为生成时快照。
