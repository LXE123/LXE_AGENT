# 马帮 TMS 数据导出

## 范围

- 用户明确提到马帮 TMS、TMS 或旧称智汇 TMS 时使用。仅说“马帮”且上下文无法确定系统时，先用已有问答工具区分马帮 ERP 与马帮 TMS；不混用两套账号。
- 默认导出当前账号可见的全部仓库、正常商品、全部库存状态。库存、销量、商品资料使用同一次商品导出，不分别执行；不能把当前账号范围说成固定菲律宾。
- 字段固定，按实际返回表头解释；保留额外销量字段 `sale5`，不猜其窗口。“入库时间”不等于已确认的首次入库或上架时间。
- 指定仓库、日期、历史库存、逐日销量、独立上架报表或自选字段均超出本命令能力，先说明限制并确认是否接受默认范围。取消或跳过时停止。

## 执行与交付

通过 `exec` 调用，不传凭据，不自行拼 API，也不先预览：

```text
lxeskill mabang-tms export run
```

- 账号密码在桌面“马帮 TMS”配置。每次任务登录一次，各批复用内存登录态。命令运行中等待同一执行，不重启导出。
- 只以最后一条 `type="result"` 的 `ok / data / error / files` 为结果。完成需脚本确认所有接口记录及各批文件通过校验；一批成功、页数或文件存在不能代表全量完成。
- 独立导出把 terminal `files` 交给 `send_files` 一次；东南亚入口调用时交回入口统一发送。发送成功才称已交付，发送失败只重试发送。
- 交付的是生成的合并 Excel，平台原始分批文件本地保留。合并只追加行，不按 SKU 去重、累加销量、删改负库存或零价格。同 SKU 多行可能重复携带销量，不能直接相加。
- 按结果分别说明接口总记录数、已读取／已导出唯一 ID 数、完成批次数、导出行数、不同 SKU 数和实际仓库；零记录且无文件时明确没有数据，不声称已发送 Excel。
- `ok=false` 且 `data.status=partial_success` 时，可发送 `files` 中的部分文件，同时说明实际错误、已完成范围和剩余记录，不能称全量完成。失败不自动重跑、不刷新马帮 ERP 登录；用户明确重试才执行新任务。
- 错误转述实际脱敏诊断，不读取或展示账号密码、Token、签名下载 URL。不进行备货计算。
