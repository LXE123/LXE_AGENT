# 马帮 TMS 数据导出

## 业务范围

数据来自马帮 TMS 当前配置账号可见的全部仓库，范围为正常商品、全部库存状态。本业务涉及 Shopee，实际取数范围由账号决定，不固定为菲律宾或其他国家。

马帮 TMS 与马帮 ERP 是不同的取数系统，使用各自配置。仅凭“马帮”或“Shopee”不能唯一确定数据来源。

## 报表字段

商品、库存和销量在同一份报表中：

| 数据 | 已核实字段 |
| --- | --- |
| 商品与仓库 | 库存SKU、仓库、入库时间 |
| 库存 | 库存量、可用库存、在途量 |
| 销量 | 7天销量、15天销量、30天销量 |
| 金额 | 成本价、采购价 |

商品名称不保证存在；其他销量窗口以实际表头为准。销量是对应周期的累计量，不是逐日明细；入库时间未确认等于首次入库或商品上架时间。

## 获取命令

```bash
lxeskill mabang-tms products export
```

命令不接受筛选参数，账号密码来自桌面“马帮 TMS”配置。原始分批文件可能为 XLS 或 XLSX，本地保留；最终交付固定为一份合并后的 **XLSX**。合并只追加行，不按 SKU 去重或累加销量，也不删改负库存、零价格。

结果提供文件路径、实际涉及的仓库、导出行数、不同 SKU 数及完成情况。部分成功时可产生部分导出文件；零记录时可能没有文件，均以结果中的 `files` 和实际完成范围为准。

## 限制

- 当前命令不支持按仓库、销售平台或日期筛选，也不提供历史库存、逐日销量、独立上架报表、自选字段或备货计算。请求超出能力或来源不明确时，先说明限制并确认可接受的范围，不静默扩大导出范围。
- 同 SKU 多行可能重复携带销量，不能直接相加；库存字段沿用原表口径，不据列名推导计算关系。
- 结果中的仓库仅表示本轮数据涉及的仓库，不代表账号全部仓库清单。Shopee 业务背景也不代表已按平台过滤，不能据 SKU 或商品名称推断平台归属。
