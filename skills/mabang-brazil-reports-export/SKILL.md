# 马帮巴西海外仓导出

## 业务范围

数据来自马帮 ERP，当前固定为“巴西海外仓”。本业务涉及 Shopee，但命令按仓库取数，不提供销售平台筛选，也不能据 SKU 推断具体店铺或平台归属。

## 报表内容

| 报表选项 | 内容与范围 | 交付格式 |
| --- | --- | --- |
| `inventory-sales` | 当前库存动销，包含 7／28／42 天累计销量 | 原始 XLSX |
| `pending-transfers-within-3-months` | 平台默认三个月内的待签收调拨明细 | 分批原始 XLS |
| `received-transfers-before-3-months` | 平台三个月前的已签收调拨明细 | 分批原始 XLS |

- **库存动销字段**：库存SKU编号、仓库、仓位、销量(7)、销量(28)、销量(42)、仓位库存、可用库存量。商品名称不保证存在；库存和销量共用这一份报表。
- **调拨字段**：批次编号、库存SKU、中文名称、起始／目标仓位、起始／目标仓库、调拨数量、待签收数量、总入库数量、签收量，以及发货日期、预期到货日期、最近签收日期和签收日期等。

## 获取命令

```bash
lxeskill mabang brazil reports export --report inventory-sales
```

`--report` 必填，可重复，选项见上表；可在一次命令中选择多类报表。命令使用当前马帮 ERP 配置，开始业务前按需恢复登录态，和马帮 TMS 的认证独立。认证失败或导出中途失败时保留实际诊断及已完成文件，不额外刷新或重跑整段导出。

结果提供文件路径、库存记录数、调拨单据数、文件明细行数、批次数及完成情况，这些数量口径不同。调拨报表每批一份 XLS，可能产生多份文件；各文件保留平台原样，不合并、裁列或转换格式。部分成功时，`files` 只包含已完成的可交付文件，不代表全部报表齐全。

## 限制与字段口径

- 当前命令不支持其他仓库、自定义日期、历史库存、其他销量窗口或备货计算。请求超出能力或来源不明确时，先说明限制并确认可接受的范围，不静默替换。
- 三个月范围沿用平台快捷筛选，不能直接解释为签收日期范围；各日期列保留原表含义，不推断首次入库或商品上架时间。
- 销量是 7／28／42 天累计量，不提供 15／30 天或逐日销量。库存字段沿用原表口径，不据列名推导库存公式，也不按 SKU 自动去重或累加。
