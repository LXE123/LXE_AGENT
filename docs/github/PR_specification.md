# PR 与提交说明

一个 PR 聚焦一个问题，描述最终行为及验证结果，让没有参与开发的人也能评审。

- 先说明具体问题、改动后的行为，以及必要的影响范围。
- 列出实际执行的验证与结果；未覆盖的平台或场景明确标注。
- 保留会影响维护的决策和限制，删除临时讨论、重复文件清单和已放弃方案。
- 标题与提交说明使用英语，类型前缀和仓库协作流程以 [AGENTS.md](../../AGENTS.md) 为准，例如 `docs: align desktop documentation with current behavior`。

Windows 发布、安装和升级验收见 [打包手册](../desktop/packaging-pipeline.md)。修改文档时同时检查链接与过时引用。
