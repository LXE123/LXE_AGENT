# Agent 桌面界面改版

日期：2026-11-02。任务分支：`codex/dashboard-ui-refresh`。

## 目标和方向

以用户提供的 WorkBuddy 截图为布局主参考，借鉴 Accio Work 截图的简洁感。保留 LXE Agent 品牌、工作空间、技能、工作台、定时任务、模型、权限和文件预览等现有能力。

先完成可操作的界面，再确认布局，随后细化公共组件，最后覆盖其他功能页。参考图只提供视觉方向，不代表加入其中的积分、签到、语音、专家团或吉祥物。

## 阶段与验收

| 阶段 | 工作内容 | 验收标准 |
| --- | --- | --- |
| 一：界面布局 | 合并左侧导航和任务列表；重做新建任务页、输入区；衔接对话及文件预览 | 入口可用、真实输入可以发送；原有功能可达；窄窗口不横向溢出 |
| 二：确认布局 | 查看运行效果，调整信息层级、宽度、间距和响应式表现 | 用户确认整体方向，明确需要修改的细节 |
| 三：细化组件 | 基于 Radix Primitives 封装 LXE 公共组件；统一按钮、菜单、弹窗、选择器 | 统一外观、键盘焦点及加载、禁用、错误状态；业务页面经公共入口使用组件 |
| 四：全面统一 | 将确定的组件和视觉规范应用到技能、工作台、定时任务和设置等页面 | 浅色、深色和窗口缩放表现一致，关键流程通过回归 |

## 第一阶段设计

左侧使用一个完整侧栏：品牌与搜索、醒目的新建任务、功能导航、按工作空间组织的历史任务、底部设置与更新。收起后保留图标入口；展开后显示文字和任务列表。保留原工作概览和使用统计入口，避免丢失现有信息。

新建任务页采用居中的问候、少量任务模板和大输入区。模板只填入草稿，由用户编辑和发送，不自动执行或按关键词分流。输入框沿用 Lexical，保留附件、文件与技能引用、模型选择、思考强度、权限及停止等现有机制。工作空间控件紧邻输入区。发送后使用现有对话布局，文件预览仍在右侧。

视觉采用白色主区域、冷浅灰侧栏、细边框和大圆角输入区。绿色用于新建任务、选中状态与发送动作；快捷模板的图标使用绿、蓝、紫、橙作少量区分。沿用 HarmonyOS Sans SC 字体。浅色设计基色为侧栏 `#f5f8fa`、画布与输入区 `#ffffff`、文字 `#172a32`、边框 `#dfe8ec`、强调色 `#007c5c`、选中底色 `#e3f6ed`；暗色通过同用途变量适配。首页留白集中在输入区周围，复杂执行内容保留阅读宽度。

```text
品牌 / 搜索       │
新建任务          │       今天想完成什么工作？
技能与连接        │
工作台 / 定时任务 │       常用任务模板
工作概览 / 统计   │       ┌──────────────────────┐
                  │       │ 描述任务，添加文件或引用 │
工作空间与任务    │       │ 附件 / 权限 / 模型 / 发送│
                  │       └──────────────────────┘
设置 / 更新       │       工作空间
```

第一阶段复用已有组件，仅在职责清楚的地方拆分布局；暂不安装 Radix 或全面替换交互组件。第二阶段确认后，再用 Radix 处理通用交互，LXE 组件控制外观和项目约定。主题变量、基础组件、通用组合组件、业务组件和页面各自分层，避免页面继续堆积零散样式。

界面交互入口变化按 [PR 审查规范](../pr-review.md)提交人工审核。未经明确授权不合并 PR。现有 CDS 来源资料保留其证据属性，新布局属于 LXE 的产品设计，不冒称外部设计系统规范。

### 配色调整

根据首版实机反馈，去掉偏灰绿的大面积底色，改为白色画布、冷浅灰侧栏和翡翠绿主动作；任务模板仅在图标上加入分类色，工作空间底板改为更轻的浅色。保持原布局和交互。

悬停反馈使用独立底色：浅色 `#d3e9df` 搭配深绿文字 `#173e2f`，深色 `#314f43` 搭配浅色文字 `#edfff6`。选中项悬停使用更深一级底色；任务模板悬停底色增加分类色占比并强化边框，输入工具栏和侧栏辅助按钮沿用同一悬停层级。

选中反馈同步加深：浅色底色 `#b9dfcb`、文字与图标 `#124430`；深色底色 `#285540`、文字与图标 `#dffff0`。导航和会话列表使用同一组变量，选中项悬停时再加深一级，避免与普通悬停混淆。

### 按需查看执行详情

思考和工具执行过程默认收起，标题按实际阶段显示简短状态并提供“展开详情”；未知阶段显示“处理中”。用户手动展开后保留阅读选择，不在完成或失败时自动改变。历史过程同样默认收起，最终回答、产出文件、审批和结构化问题仍直接显示。此改动只调整展示，不改变模型配置、执行流程和存储。

工作空间底板上移至输入卡片后方，消除两层之间的缝隙；控件仍位于输入卡片下方。输入卡片与菜单保持上层，底板位于下层；出现错误、队列或审批卡片时保留独立间距，避免遮挡信息。

思考强度切换时，保存锁定保持原有逻辑，但模型与强度文字不再临时变淡。强度按钮预留各档位标签所需的宽度，取消保存加载图标，通过档位滑杆的平滑移动反馈切换，避免保存前后横向跳动。保存失败仍回退实际档位并显示真实错误。

思考强度沿用档位滑杆交互：点击时滑块与填充区域用 200ms 过渡，拖动跟手、松手吸附。显示使用当前主题的绿色，保存期间不显示加载动画。滑杆保留手势目标，避免松手后在乐观更新到达前闪回旧档位；失败时仍回退服务端实际值。系统“减少动态效果”设置会关闭过渡。

依据用户补充的 Codex 截图调整思考强度浮层：当前档位居中、模型名称置于下方；左侧保留说明入口，右侧提供恢复默认档位。轨道填充放在外层，滑块中心轨道内缩一个半径，确保圆形滑块到达最低或最高档时与轨道外缘贴合，不留下空白端帽。保留绿色主题与原有滑动过渡。
