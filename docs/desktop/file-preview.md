# 侧边栏与文件预览

点击 Agent 交付的文件卡片或已发送附件即可预览：对话里的图片使用居中弹窗，其他文件在聊天右侧查看。工作区文件树里的图片继续在右侧文件标签中打开。图片弹窗可通过关闭按钮、Escape 或点击遮罩关闭，不改变原来的侧栏标签和输入草稿；切换会话时关闭弹窗并释放图片资源。聊天顶部的侧栏按钮显示或收起工具栏，在“开始”页点击“工作区文件”浏览当前会话目录；顶部的分体按钮可选择已安装应用打开工作区，规则见[用应用打开目录](conversation-window.md#用应用打开目录)。

- 每个会话分别记住标签、活动文件和宽度；打开同一文件会复用标签。方向键、Home/End 可切换标签，活动标签自动滚入可见范围。
- 阅读位置、查看方式、缩放、工作表和选区只保存在内存；切换标签、会话或收起侧栏会保留，关闭标签或删除会话会清理。重启只恢复布局，不恢复阅读位置，也不写 Agent DB。
- 拖动侧栏左边缘调整宽度，也可以展开。窗口较窄时预览占满聊天区域，关闭即可回到原来的聊天和输入草稿。
- 文件树显示实际工作区路径、隐藏文件，目录按需展开，每层 200 项分页。可打开系统文件管理器。展开目录自动监听变化；隐藏侧栏后释放监听，返回时重新核对。刷新保留旧列表直到新结果就绪。
- 文件卡片和预览工具栏中的图标打开系统默认应用；下拉菜单可以选择其他关联应用或定位文件。选择只影响本次打开。无默认应用时选第一个关联应用；没有关联应用时仅提供文件定位。同文件卡片和工具栏共享应用查询。
- 聚焦侧栏时，macOS 使用 Cmd+W/Cmd+R，Windows 使用 Ctrl+W/Ctrl+R 关闭当前标签或刷新预览。菜单、弹窗优先处理。

## 侧边栏入口

首次展开显示“开始”，可打开工作区文件、新建终端或浏览器。顶部“＋”回到开始页，选择工具替换开始标签；最后一个标签关闭后显示开始页。聊天顶部通过侧栏开关显示工具栏，文件树从开始页进入；对话顶部和文件树顶部的分体按钮可用外部应用打开目录。文件链接仍直接打开预览，旧文件标签和侧栏宽度继续保留。对话中的图片附件、图片产出卡片和图片引用点击后居中弹窗放大；文件树中的图片仍在右侧文件标签中预览。

## 手动终端与浏览器

手动终端使用 xterm.js 与 node-pty，从会话工作目录启动系统 Shell：macOS 为用户默认 Shell，Windows 优先 PowerShell 7，其次 Windows PowerShell。每会话最多 8 个终端，保留有限输出。切换对话、折叠侧栏、界面刷新和隐藏到托盘不结束进程；关闭终端、删除会话或完整退出应用会清理进程。应用重启后，终端标签显示已结束，由用户重新打开，不自动执行旧命令。

浏览器使用 Electron WebContentsView，支持 HTTP/HTTPS、地址栏、前进后退、刷新和多个标签。同一工作区共享本次运行的登录状态，不同工作区隔离，完整退出后清除；隐藏到托盘不算退出。浏览器禁止下载，也不能访问应用接口或本地文件。应用重启后恢复保存的网址，登录状态重新开始。

这两类工具只供用户手动操作，不进入模型工具列表，也不与 Agent 的命令执行或紫鸟浏览器共用资源。Bun Runtime 仍是会话状态的唯一属主；Electron 管理工具资源，PTY 位于独立 utility process。node-pty 的 Node-API 二进制与 spawn helper 放在 ASAR 外，构建后通过 `bun scripts/verify-manual-tools.ts` 在真实 Electron 中验证。

## 支持内容

Markdown 支持公式、Mermaid 和受限的本地图片，可切换渲染与纯文本。代码提供行号、高亮、换行和复制；CSV 可切换表格、代码、纯文本，TSV 可切换表格与纯文本，SVG 可切换图片与源码。

文本流式分页，每页最多 5,000 行、2 MiB，不限制整文件大小；超长页明确报错，不截断。接近底部或点击“加载更多”继续读取，支持 UTF-8 和带 BOM 的 UTF-16。未读完时复制按钮明确标注“复制已加载内容”，保持原换行，不读取剩余文件。Markdown 按已加载的完整前缀重新渲染，跨页代码围栏可以继续完成。

图片和 PDF 共用底部缩放条，支持适应宽度、25%–400% 缩放、触控板捏合及 Ctrl+滚轮。图片 100% 对应固有 CSS 像素，PDF 100% 对应 96 DPI；PDF 可跳页、旋转和选择文字，单页画布不超过 16,777,216 像素。连续调宽时保留旧画面，稳定后更新视口附近页面。Word/PPT 使用随应用提供的 LibreOffice Kit 0.1.5 转为临时 PDF，缺失字体通过工具栏警告按钮展开。

Excel 是只读表格，可选择、复制、切换工作表和查看公式栏。它显示文件保存的公式缓存，不重新计算；缓存缺失和检测到的图表、图片等遗漏会提示。CSV/TSV 中的前导零等字面值保留。其他不支持的格式提供系统打开入口。

HTML（`.html` / `.htm`）默认显示“网页预览”，也可切换到分页、高亮和可复制的“源码”。适合单页报告、图表和小型交互演示。支持内嵌 CSS、JavaScript，以及 HTML 直接引用的相对 `.css` 和普通 `.js`。data 图片、网络图片／脚本和网络请求交给浏览器，受 CORS 与混合内容规则约束；含 `<base href>` 时，相对资源也交给浏览器解析。

第一版不打包独立本地图片、本地模块 import、CSS `url()` / `@import`、动态本地 `fetch` 或多页面工程。需要本地图片时可将图片转为 data URL。HTML 预览不是网站浏览器；页面不具备文件读取、应用 IPC 或 Node 权限，也不连接手动浏览器、紫鸟或 Agent 工具。刷新、切换查看方式或重新挂载后脚本重新运行，页面中的交互状态不保存。

已发送图片使用会话保存的历史图片；工具结果图片和草稿附件沿用原交互。系统应用打开的是原文件。原文件缺失但历史图片可读取时，仍显示发送时的图片，并标记“源文件不存在”；系统打开和定位不可用。

## 文件删除与错误提示

交付文件被移动或删除后，卡片仍保留在聊天中。文件名旁显示中性的“文件不存在”，右侧打开按钮禁用，卡片高度不变。点击卡片可查看说明、重新检查，并展开或复制实际错误详情。

正在预览的文件失效时，侧栏立即清空文档内容、释放 Worker、文件句柄和转换任务，保留标签与阅读偏好。活动标签每 1.5 秒检查一次，也会在窗口重新获得焦点时检查；首次打开就不存在的文件同样可以自动恢复。文件回到原路径后重新加载，并恢复有效范围内的阅读位置。收起或切换标签后停止轮询。卡片仅在可见、窗口恢复焦点或用户操作时检查，不逐项轮询。

权限不足单独提示。后台应用列表查询失败只在菜单中显示摘要、重试和详情；主动打开或定位失败显示一次短暂提示，查看详情时暂停消失。缺少 Node、Office 引擎或系统辅助程序不会误标成用户文件被删除。此功能不备份文件、不寻找新位置，也不写业务数据库。

## 边界与资源

文件引用只接受会话内的产物 ID、附件 ID 或工作区相对路径。Bun 运行时提供记录及工作目录，桌面检查规范路径和符号链接。Markdown 图片仅能读取文档所在目录及其子目录中的图片，不允许读取任意宿主路径。

HTML 依赖在主进程读取：工作区文件限当前工作区，工作区外的已登记附件／产物限其所在目录及子目录。规范路径与符号链接检查通过后，才发布完整内存包；每个关联资源最多 4 MiB、最多 64 个不同引用，HTML 和依赖合计最多 32 MiB，统一严格 UTF-8 解码。缺失、编码错误或超限会显示真实诊断并提供重试，不发布残缺页面。活动预览沿用 1.5 秒及焦点检查，HTML 或已加载 CSS／JS 变化时重新准备。

预览通过标准 Electron `lxe-preview:` 协议访问临时令牌，URL 不映射任意磁盘路径。iframe 使用 `sandbox="allow-scripts"`，只有隔离页可以创建资源 Blob；不授予同源、弹窗、表单、下载或顶层导航权限。主界面 CSP 仅增加该 frame 来源，其自身脚本权限保持不变，也不启用 CSP 绕过。关闭、切换或卸载时释放请求、内存包与 Blob；字节、临时 URL、脚本状态不写入会话 DB 或标签布局。

文件内容使用短期句柄：二进制和文本分页分别走受限 IPC，不进入聊天 JSON 或持久界面存储。文件树仅缓存目录条目，阅读状态不保留文档字节或完整工作簿。预览不修改源文件。仅活动标签保留内容；关闭或切换会释放 Worker、句柄及不再使用的转换任务。文件监听配合活动轮询、窗口焦点检查与手动刷新，过期结果不会替换新结果。

限制：普通文件 50 MiB，文本每页 2 MiB / 5,000 行，表格 16 MiB / 25 万单元格 / 15 秒解析，Office 转换 60 秒。Electron 主进程通过 Kit Node API 按需创建并复用 Converter，转换串行且合并同文件请求；最后一个使用方取消时通过 AbortSignal 终止转换，由 Kit 清理 worker 和原生任务，关闭服务时 dispose。缓存位于应用数据目录的 `cache/file-previews/`，按内容和 Kit 版本复用，512 MiB / 七天闲置清理，正在使用的缓存保留。

PDF/表格查看器及 Worker 按需加载。PDF 字体、CMap、WASM 和许可证都随包提供。Windows Shell 辅助 PowerShell/C# 代码编译进桌面主程序，查询时写入专用临时目录并清理；macOS 使用 JXA/AppKit。Windows 菜单采用 Shell 为该文件类型提供的推荐关联应用，避免混入无关的全局应用注册项。应用查询失败保留错误，不当作“没有关联应用”。

## 验证命令

从仓库根目录执行，使用该 worktree 自己的环境：

```sh
bun test apps/desktop/test/file-preview.test.ts apps/desktop/test/file-applications-windows.test.ts scripts/file-preview-resources.test.ts apps/dashboard/test/features/file-preview
bun test apps/desktop/test/html-preview.test.ts apps/dashboard/test/features/html-preview/renderer.test.ts
uv run --frozen python scripts/create-file-preview-fixtures.py
bun scripts/verify-file-preview.ts
```

最后一个命令接受三个可选位置参数：样本目录、内置运行环境目录、验收输出目录。Windows 打包验收将第二个参数指向安装目录的 `resources/runtime`。报告记录真实转换错误、缺失字体和转换前后源文件哈希。

界面测试通过生产 `app://` 资源处理器运行，阻断外部网络请求，并检查实际 PDF Worker 在切换标签后释放。Windows 原生关联测试在其他平台明确跳过。

HTML 界面测试使用生产文件服务、IPC、preload、CSP 和真实 Electron iframe；本机 HTTP 夹具验证网络资源与 CORS，不依赖公网网站。它同时覆盖生产 `app://` 与开发 HTTP 来源、源码切换、依赖刷新、错误重试、会话切换和资源释放。可用 `LXE_HTML_SCREENSHOT` 保存测试窗口截图。

Windows 解包后可执行 `bun scripts/verify-packaged-html.ts dist/desktop-unpacked/win-unpacked`。脚本复制实际可执行文件到独立临时目录，关联原包资源，以独立 `var` 启动真正的打包程序；通过本机调试接口驱动生产 Runtime、文件 IPC 和 iframe，验证相对资源、交互及隔离，保存截图与 `report.json`。不调用模型，不读取原安装目录的数据，不连接紫鸟；测试结束退出应用。主界面完整刷新或 Renderer 退出时，主进程也会释放预览，避免依赖 React 卸载回调才能清理。

`scripts/verify-preview-native.ts` 可先用 Bun 打包为 Node CJS（将 `electron` 保持 external），再用目标平台的 Electron 执行。它检查真实默认应用、指定应用、图标、文件定位和工作区打开，并生成 `report.json`。Windows 需在已登录的桌面会话中执行；SSH 的 Session 0 不能代表交互式 Shell 行为。

界面验收截图来自生产查看器组件与测试夹具组成的窗口，左侧按钮及示例草稿是测试入口，不是生产聊天界面。

桌面打包入口和 afterPack 都检查 PDF 支持资源、独立查看器、两个 Worker 和许可证；缺项即失败。两平台记录见 [验收记录](../acceptance/file-preview-acceptance.md)。

文件错误通过独立 IPC 的成功／失败结果返回，Renderer 解包后保留类别、操作和真实诊断；二进制仍为 `Uint8Array`。诊断脱敏，过长时明确标记截断。`scripts/verify-file-availability.ts` 使用生产 preload 和 IPC，在真实 Electron 沙箱里检查删除／移动、权限拒绝、恢复、历史图片、失效应用及缺失引擎；测试只修改独立验收目录内的文件与权限。

Windows 的权限拒绝验收需要普通权限桌面进程。SSH 管理员若启用备份权限可能绕过 ACL；这时脚本会明确失败，不能据此认定权限提示已验证。
