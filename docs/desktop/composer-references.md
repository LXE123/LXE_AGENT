# 输入框文件引用与技能选择

在会话输入框输入 `@` 选择当前工作区的文件或目录，输入 `/` 选择当前可用技能。也可以直接写 `/office-xlsx` 等技能名。发送的内容仍是普通文本：

```text
/office-xlsx 分析 @"报表/销售 统计.xlsx"，按月份汇总
```

## 使用方式

- 在开头或空白后输入 `@`、`/`；上下键移动，Enter 确认，Esc 退出候选。
- 目录 Enter 选中，Tab 或右侧箭头进入目录；文件与技能 Tab 确认。进入目录后显示面包屑，可以返回上级；仅手写路径时不显示面包屑。
- 候选采用紧凑单行：根目录文件只显示名称，搜索结果右侧显示父目录；已有面包屑时不重复目录。技能名称与描述放在同一行，长内容悬停可查看。
- 文件显示为整体标签，复制时保留完整路径；空格路径使用引号。技能保持可编辑的 `/名称` 文字。
- 点击输入框或已发送消息中的文件引用，在原侧栏预览；技能引用打开当前 `SKILL.md`。目录只作为引用，不打开文件树。
- 文件引用不预读文件，也不阻止发送不存在的路径；预览时沿用现有的文件失效页面。
- 附件选择、拖放、图片粘贴、排队和发送失败保留草稿沿用原有行为。Shift+Enter 换行；输入法组词期间不发送。

文件候选每次最多 20 项。空查询列根目录，普通关键词按名称和路径模糊匹配，带 `/` 的查询直接列对应目录。索引最多 50,000 项；工具结果使索引过期，下一次查询后台重建时仍提供旧候选。隐藏路径需要以 `.` 开头的查询；不使用 `.gitignore`。不进入符号链接，也不显示 `.git`、`node_modules`、`dist`、`build`、`out`、`coverage`、`target`、`.next`、`.nuxt`、`.turbo`、`.venv`、`__pycache__`、`.pytest_cache`、`.mypy_cache`、`.gradle` 等排除目录，包括手写完整路径时。

## 技能与状态

只有直接用户输入中由空白分隔的有效 `/技能名` 会触发加载。已禁用、不在当前权限内或未知的名称仍是文字，路径和分数不算技能。运行时在请求模型前加载完整正文、资源根目录，并接入原有技能激活和工具开放逻辑；同批去重。附件正文、工具结果、系统事件和历史回放不会触发。

实际加载记录保存在 Bun 原有会话历史中。聊天只显示用户输入和实际加载过的技能标记，不显示内部指令，也不伪造工具调用。后续技能目录变化不会重新判断过去是否加载成功；点击历史标记查看的是当前技能文件。

草稿继续按会话保存规范文本到 `sessionStorage`；8192 字符限制按该文本计算。编辑器和撤销记录只在内存中，关闭会话时释放，闲置会话缓存有数量上限。没有引用数据库表。文件补全与技能预览都由运行时验证会话并解析路径，不接受 Renderer 提交任意宿主路径。

## 实现入口

- `ReferenceComposer.tsx`：Lexical 0.49.0 编辑、候选和输入法处理。
- `composer-references.ts`、`file-references.ts`：dsh 语法、排序、受限工作区搜索。
- `DashboardService`：会话文件候选与技能查询。
- `skill-invocations.ts`、`TypeScriptAgentRuntime`：显式加载及历史记录。
- `SessionFileRef.kind = skill`：复用受限文件预览 IPC。
