# 从现有 FBA ERP 按钮进入

公司云端的 FBA ERP 快捷入口保持原位置。管理员点击后，主进程使用本机身份凭据请求目标为 `erp` 的一次性登录码，通过浏览器 fragment 交给 ERP 页面兑换；业务运行凭据和根身份凭据都不交给网页。普通成员仍打开 `/erp` 并使用采购密码。

需先部署支持 ERP 专用会话的服务器，再更新客户端。旧服务器、不匹配的登录码或权限拒绝会显示实际错误，不自动退回旧管理员 Key。ERP 业务权限和管理员角色分别校验，禁止因缺少 ERP 权限误改管理员身份。

ERP 网页使用独立浏览器会话，刷新可保留认证。会话失效后重新点击本按钮；原 ERP 标签页可通过“重新检查认证”继续编辑，确认前必须重新预览。云端管理后台的入口和会话不受影响。
