# 越南备货来源与运营 SKU 表准备

本层在输入资产契约之上提供雅仓来源采集、来源校验、SKU 参数解析以及运营回填表的准备能力。不生成最终备货量或五表工作簿。

`export_vietnam_sources()` 复用现有雅仓 workflow，一次采集 VN8806 库存动销、VN8806 当前库存列表和全局仓库产品资料。仓库产品资料按本轮越南 SKU 精确筛选；不重新实现认证或下载。三类导出必须都成功，来源与仓库身份必须正确。本轮 SKU 是动销与当前库存两表的并集。缺一侧来源的 SKU 保留并给出缺项诊断。

总在途以当前库存列表的 `在途数量` 为权威；动销表在途仅用于差异提示，不填补当前库存表空值。仓库产品资料的 `创建时间` 保留为原始数据，后续生成层根据已确认业务口径将它用作真实上架时间。本层不改写导出文件。

`prepare_operator_sku_map(template_path, output_path, current_map_path=None, sources=None)` 是历史模板辅助能力：从本轮 SKU 集合生成运营可填写的映射表和参考页；显式参数可带入，历史模板值只作核对参考，不自动变成运营显式输入。传入 `sources` 可避免再次采集；未传时才调用一次雅仓采集。目标路径已存在会拒绝覆盖。

`resolve_sku_parameters()` 提供历史模板参考解析。当前五表生成由 `generate_vietnam_workbook()` 使用内置骨架和调用方提供的映射表路径；后续在线接线将从受信 SKU current 提供该路径。生成不从模板历史价格兜底。运营映射表以精确 SKU 为键，空白与显式零不同，不借用相似 SKU。

测试使用合成 XLSX 与 mock；真实模板、雅仓导出和业务价格不得提交 Git。本层不提供聊天或 CLI 一键入口；五表生成由独立的 Workbook 服务提供。

## 稀疏映射的生成结果

生成以本轮动销与当前库存的 SKU 并集为行集合，映射表按精确 SKU 左连接。没有映射行时只留空热销、成本、价格、备货天数、备货量和财务列；有行而个别价格为空时只留空其依赖财务结果。来源表、库存、销量、总在途和不依赖映射的公式继续保留。映射表额外 SKU 不进入结果。
