# 越南备货输入资产契约

本层注册两个由 Desktop 管理的资产槽，并提供只读工作簿校验。资产绑定、在线取数与生成属于后续模块；本层不执行这些步骤。

| 槽位 | 本层用途 | 后续生成口径 |
| --- | --- | --- |
| `vietnam_replenishment_template` | 保留旧业务模板的历史兼容槽位与校验入口 | 五表生成使用应用内置的无历史数据骨架，不读取此槽位的 `current` |
| `vietnam_sku_parameter_map` | 运营维护的 SKU 参数表槽位 | 生成前必须有已校验的 `current`；绑定及版本管理由后续模块提供 |

两个槽均标记为 `desktop` 管理。通用命令上传入口不得提升这些槽的版本。本层的 `validate_template(path)` 和 `load_sku_parameters(path)` 只读文件，不绑定用户附件，也不调用雅仓。

## 历史模板的校验

`validate_template(path)` 检查旧模板的五张必需表：`越南备货清单`、`雅仓库存`、`雅仓动销`、`数据更改`、`库存商品信息`；允许额外辅助表。它检查固定表头，以及主表 `AV2:AY2` 对 `数据更改!A2:D2` 的公式引用。历史 SKU 行可重复，只作为审计资料，不直接成为本轮输出。

## SKU 参数表的读取

`load_sku_parameters(path)` 读取第一张表。必需表头：`SKU`、`成本`、`跨境价`、`折扣价`、`热销标记`；可选表头：`上架时间`。列顺序不限。SKU 去掉首尾空格后精确匹配，重复或非文本 SKU 报错。成本和价格必须是有限非负数；显式 `0` 与空白不同。热销标记非空时只接受 `1` 或 `2`。输入格不能是公式。可选上架时间只接受有效的 ISO 日期或日期时间，不从雅仓商品创建时间推断。

空白参数保持缺失，不借用相似 SKU 或旧模板的历史价格。内置骨架、完整映射场景的五表生成、Office 重算和结果校验已由 Workbook 模块提供。Desktop 受信 `current` 的安装、上一版和回滚由本层版本存储提供；稀疏映射规则由后续模块负责。不能把本层只读 parser 误认为完整生成能力。

真实模板、SKU 映射表、成本和价格数据不进入 Git 或安装包。

## 受信 SKU current

Desktop 只允许通过原生选择器选择候选映射表。Python 在切换前复验 XLSX 结构、内容与 SHA-256，将不可变版本和 `manifest.json` 原子切换；同内容上传幂等，失败保留旧 current。生成读取受信 current 的私有快照，不把旧 `current/` 目录中未经清单验证的文件当作当前版。模板历史槽仍不参与五表生成。
