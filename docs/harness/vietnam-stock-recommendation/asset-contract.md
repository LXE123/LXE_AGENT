# 越南备货 SKU 映射表契约

流程入口与三份 ERP 报表要求见 [独立计算接口](calculation.md)。本文说明用户提供的 SKU 映射表，不涉及历史备货模板或资产版本槽位。

## 内容要求

读取 XLSX 的第一张工作表，按表头名称识别列，列顺序不限。必须包含 `SKU`、`热销标记`、`成本`、`跨境价`、`折扣价`，至少填写一个有效 SKU；完全空白行跳过。

- SKU 必须是非空文本，保留前导零和内部字符；去掉首尾空格后精确关联，重复值报错。
- 成本、跨境价、折扣价可分别留空；填写时必须是有限且大于零的数值，并能在 Excel 的数值精度范围内准确写入。空白不转成零，只让依赖该字段的价格和利润结果留空，不影响备货数量。
- 热销标记必填，只接受 `1` 或 `2`。输入单元格不能是公式，不自动补零、补默认标记或借用其他 SKU 的参数。
- 保留现有可选 `上架时间` 列的读取和校验：非空时须是有效日期或 ISO 日期时间；若与该 SKU 的 ERP 创建时间冲突则失败。计算实际使用 ERP 创建时间，空白下载模板不包含此列。

映射表不必覆盖全部 ERP SKU。缺少整行映射的 SKU 仍进入五表，缺失的映射字段及依赖它们的备货、财务结果留空。已有行只要求 SKU 和热销标记必填，金额允许为空。额外 SKU 不进入本轮结果，但填写要求相同。模板原始业务公式不变，生成时复用既有缺值判断：只对缺少必要金额的结果显示空白，保留公式供补齐数值后重新计算。

## 保存和校验

桌面上传和本轮 `--sku-map-file` 共用校验：普通 `.xlsx` 文件、压缩大小不超过 20 MiB、ZIP 解压声明大小不超过 100 MiB、条目不超过 1000 个，且不能包含加密条目。`validate_usable_sku_parameters()` 在只读解析时检查完整性和数值精度；计算内部传入的数据也执行相同检查。

表头有效时扫描整张第一工作表，一次汇总所有可独立判断的错误，包含工作表、单元格位置、可识别的 SKU、字段及原因，按行列顺序显示，并给出错误总数和涉及行数。同一行的多个问题分别列出；重复 SKU 即使首行有其他错误也能检出。有任何错误就拒绝整表，不跳过坏行计算。

缺失或重复表头一起列出，修正前不继续解释数据行；文件无法读取时保留真实异常，不声称已完成整表检查。桌面与命令行中的长错误消息显示总数和部分预览，并将完整脱敏明细保存到应用数据目录 `tmp/sku-map-validation/sku-map-errors-*.txt`，返回真实路径。报告仅用于诊断，不修改输入、参数或已保存的映射表；报告写入失败时明确返回实际写入错误。

保存路径是应用数据目录的 `skill-data/vietnam-stock-recommendation/sku-map.xlsx`。先校验完整候选文件再原子替换；替换失败保留原文件。计算和导出在锁内固定有效副本，运行中上传不会改动该副本。导出当前表保留文件全部内容；下载空白模板单独生成五列表头，不读取历史文件。没有版本回滚或旧数据迁移。

校验错误保留实际诊断，不用猜测覆盖异常。真实映射表、业务价格和 ERP 报表不进入 Git 或安装包。
