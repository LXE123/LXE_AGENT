ok，接下来是合同编号填写的 skill，这个 skill 专门用来填写合同编号，为什么要有一个专门的合同编号填写呢？因为合同编号里的数字有一些特殊的含义，其中最开始有一个英文前缀（前缀由对方公司决定，会有一个映射表），然后是日期（yyyymmdd），再然后就是今天填写的第几个合同，一般不会超过 3 位数。

然后呢，填写编号时，还要有一个 xlsx 文件要维护，这个 xlsx 文件里只做两件事，记录今天填写了几份合同，记录每家公司总共填写了几份合同。
好的，现在来讲讲这个 xlsx 是怎么构成的。
首先是 sheet：
- `总表`：这个 sheet 的字段为:
```xlsx
日期	供货商	合同编号	合同数	采购时间	采购金额
```
