# 马帮 TMS 数据导出：实现与验收

从 `main` 独立开发，参考 PR #65 的登录、列表和导出协议。产品名称统一为马帮 TMS，旧称智汇 TMS 仅用于理解请求；与马帮 ERP 配置、凭据和命令分开。

## 使用和范围

桌面设置新增“马帮 TMS”，填写账号和密码即可，不设生产开关。配置 v10 迁移到 v11，密码使用现有加密存储；前端只显示是否配置。清除后不从环境恢复。开发环境可以在 `settings.json` 的 `integrations.mabangTms` 配置 `managed: true` 和 `account`，密码通过 `LXE_MABANG_TMS_PASSWORD` 注入；已保存密码优先。运行时注入 `LXE_MABANG_TMS_ACCOUNT` 与 `LXE_MABANG_TMS_PASSWORD`，不接受旧 ZHIHUI 环境别名。

唯一命令 `lxeskill mabang-tms export run` 不接受参数。固定当前账号可见全部仓库、正常商品、全部库存状态；实际请求筛选保留在结果中。12 个字段沿用 PR，包含 `sale5`，不猜其窗口。每次任务登录一次，Token 仅在内存复用。

按账号锁串行执行。每页最多请求 1000 条，按内部 ID 导出，立即下载、校验并保存原始批次。只有唯一 ID 总数等于接口总数且所有批次通过校验时成功；短页不会提前结束。最多 100 页、10 万条、15 分钟。仅列表查询允许有界重试，提交、下载和认证拒绝后不自动重试。

输出目录由 catalog 的 `mabang_tms_exports` 定义，按账号摘要和运行编号隔离。原始 XLS/XLSX 字节保留，本次各批按顺序追加为一份合并 XLSX，文本销量、重复 SKU、负库存和零价格保持不变。源表公式／错误单元格、异常表头及商品仓库覆盖不符时停止；同一 SKU 多行不自行去重或求和。合并是本地生成文件，不冒称平台原件。后续批次失败时只交付已校验部分，保留原始错误；发布失败不隐藏此前的导出失败。

## 真实验收和仍未确认事项

已只读检查用户提供的 `stock_1582_20260923154347.xls`：真实二进制 XLS，50 行、41 个不同 SKU、11 列，均为菲律宾 PH1 仓。新读取器成功读取；真实业务文件及 SKU 未提交到仓库。此项仅证明文件兼容，不代表已完成真实接口调用。

目前桌面配置为 v10，无独立 `mabangTms` 账号配置，执行环境也未提供 TMS 账号密码。因此没有执行真实登录、小批接口对照或全量导出。网页导出失败的具体原因和上限仍未确认，不认定平台存在固定 8000 条限制。

真实接口验收必须检查列表记录的 `stockSku` 及 `warehouseName`（或字符串 `warehouse`）与原文件对应。PR 的分页测试仅提供 ID，未证明生产响应的这两个字段；当前实现缺少明确字段时返回 `coverage_schema_unknown`，不跳过校验后冒称全量成功。需要结合真实响应补充脱敏 fixture 后再确认该契约。

`lastInTime` 保留源表“入库时间”含义，不认定首次入库或上架。按用户要求不单独调查 `sale5`，以实际返回列名交付。新 Skill 的澄清、取消及跨流程统一交付已写入指引，尚未以真实模型会话验收全部交互分支。
