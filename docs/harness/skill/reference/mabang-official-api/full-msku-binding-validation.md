# 全量 MSKU 与 Listing 绑定核验

从 2026-09-08 起，备货不再用马帮 Active 状态筛选商品。网页 XLSX 保留全部行；官方 Listing 不传 `pStatus` 或其他状态过滤，只用于核对本地 SKU 和普通／组合类型。

- 下载仍限定单店、单站点，网页下载 ID 与官方 `sid` 各用其原有用途。保留店名别名、完整分页和跨店铺／站点检查。
- MSKU＋ASIN 唯一匹配后核对本地 SKU；ASIN 为空必须无歧义。绑定变化、类型冲突或同 MSKU 的 ASIN 不一致仍报错。源表本地 SKU 为空时保留空值。
- 未匹配记录保留在源表和全量销量分析中，写明未核验原因，不查询它的组合和深圳库存，也不进入备货计算。`Amazon.Found.*` 不作名称例外。
- 源表追加“绑定核验结果”“是否通过绑定核验”“未通过原因”。隐藏“源数据核验信息”使用版本 2、范围 `xlsx_all`，保存本轮 Listing、源指纹、未通过记录的完整商品键及原因。下游传递核验信息；计算入口用明确标识排除未核验记录，不能将其当作普通 SKU 或仅靠空库存判定。
- MSKU、ASIN、链接三个销量汇总维度均使用全量源表。最终备货和链接备货汇总只来自符合绑定核验及现有计算条件的记录。
- 返回 `original_row_count`、`binding_verified_row_count`、`binding_unverified_row_count`，前者等于后两者之和。通过绑定核验不等于有库存或建议发货，不再返回 `active_row_count`／`excluded_row_count`。
- 历史 Active 文件不修改，也不自动迁移。新计算需重新下载，生成同轮新版销量与库存报表。核验不一致立即失败。
- 无可计算记录时不生成备货建议；仍可输出全量销量及库存异常明细。保留下载原子发布、最终报表原子发布、真实错误和现有超时。

真实模型 Skill 行为回放由用户验收，不作为本次代码合并阻塞，也不调用外部模型代测。
