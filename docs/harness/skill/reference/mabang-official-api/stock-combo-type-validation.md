## 真实接口依据（2026-09-10）

官方库存 SKU API 为 `stock-do-search-sku-list-new`。请求使用 `stockSkuList` 英文逗号分隔，
`maxRows=1000, way=2`。实际成功数据是 `data.data` 和 `data.nextCursor`，不带文档示例中的总页数。
游标非空时保持批次条件续查；空字符串表示结束。正常无命中、完整游标分页的终止空页均返回
`data.data=null, nextCursor=""`，不能把字段缺失当成正常空结果。

已用 5 个库存 SKU 与 5 个已知组合混合查询：仅 5 个库存 SKU 返回，5 个组合明细另经官方接口确认。
另以 `maxRows=2` 实测“2 条 → 2 条 → null 终止页”，脱敏投影保存在
`python/lxeskill_cli/tests/mabang/fixtures/stock_sku_cursor_contract.json`。
这不能证明所有未命中项都是组合，仍必须继续查询组合明细。
