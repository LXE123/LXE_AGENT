# Python 3.12.10 / uv 部署说明

本项目统一使用 uv 管理 Python 版本、虚拟环境和依赖锁定。

## 一键安装

在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

脚本会自动完成：

- 安装或发现 uv
- 安装 Python 3.12.10
- 按 `uv.lock` 同步 `.venv`
- 安装 Playwright Chromium
- 执行基础 import 检查

## 手工命令

```powershell
uv python install 3.12.10
uv sync --frozen --all-groups --python 3.12.10
uv run --frozen python -m playwright install chromium
uv run --frozen python -c "import sys; print(sys.version)"
```

Python 只用于按需执行的一次性工具；生产 Gateway 使用 Bun：

```powershell
C:\Users\Administrator\.bun\bin\bun.exe run gateway:start
```

运行 Python 工具桥可使用：

```powershell
uv run --frozen python -m lxeskill.bridge
```

## 依赖管理规则

- `pyproject.toml` 是直接依赖声明入口。
- `uv.lock` 是部署时的依赖真相来源。
- 不再维护 `requirements.txt`。
- 添加运行依赖：`uv add <package>`
- 添加测试/开发依赖：`uv add --dev <package>`
- 更新锁文件：`uv lock`

## Windows Node/MSI 排障

Dashboard UI 构建依赖 Node.js 和 npm。如果安装时出现：

```text
Node.js installation finished, but node/npm is still unavailable.
```

同时 Windows Installer 弹窗提示“无法打开此安装程序包”，不要先判断为电脑不支持 MSI。常见原因是 Node MSI 没有正确下载，或下载 URL 无效，导致 `msiexec` 打开了不存在、空文件或损坏的安装包。

先确认 Windows Installer 服务：

```powershell
Get-Service msiserver
Start-Service msiserver
```

再直接下载固定的 Node x64 MSI，并确认文件真实存在且大小正常：

```powershell
$msi = "$env:TEMP\node-v22.17.1-x64.msi"
$log = "$env:TEMP\node-msi-install.log"
$url = "https://nodejs.org/dist/v22.17.1/node-v22.17.1-x64.msi"

Invoke-WebRequest $url -OutFile $msi
Get-Item $msi
(Get-Item $msi).Length
```

确认 MSI 文件正常后再安装，并写入日志：

```powershell
Start-Process msiexec.exe -Wait -Verb RunAs -ArgumentList "/i `"$msi`" /L*v `"$log`""
```

安装后新开 PowerShell 验证：

```powershell
node -v
npm.cmd -v
```

如果 `npm -v` 被 PowerShell 执行策略拦截，是因为它优先命中了 `npm.ps1`。可改用 `npm.cmd -v`，或仅在当前窗口临时放开：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
npm -v
```

Node 和 npm 正常后，回到项目目录继续：

```powershell
cd "$env:USERPROFILE\.lxe_agent"
powershell -ExecutionPolicy Bypass -File ".\scripts\webui.ps1" -Build
powershell -ExecutionPolicy Bypass -File ".\scripts\launcher.ps1"
powershell -ExecutionPolicy Bypass -File ".\scripts\doctor.ps1"
```
