# 雅仓数据导出域（2026-09-13）

本域提供雅仓导出的公共认证、队列、下载、安全校验和业务适配层。第一版任意创建日期范围库存动销入口继续保留；受控的 7/15/30 与日度 90 天销量使用统一 `yacang export` 命令前缀，并将业务文件写入 `yacang/exports`。

## 边界

- Python 仍不读写 Bun Agent 会话数据库；雅仓的非敏感 cooldown、请求串行锁和导出幂等标记使用现有 Python CLI 数据库，不建立 Agent 会话影子表。本地产物缓存可随时删除。
- 登录凭据由 Desktop 安全存储管理，通过 `LXE_YACANG_MOBILE`、`LXE_YACANG_PASSWORD` 注入单次进程。Token、验证码和远端文件地址不落盘、不进入结果或日志。
- 真实雅仓访问默认关闭；只有显式 `LXE_YACANG_PROD_ENABLED=true` 且凭据完整时才允许发出请求。凭据存在本身不能开启生产访问。
- HTTP 调用使用现有外部请求运行时，不引入页面自动化，也不依赖紫鸟浏览器状态。
- 所有生产请求通过跨进程串行门禁并保留最小间隔。分仓导出只允许四个已确认仓库，按业务、仓库和日期范围持久化去重；任何创建远端任务的请求无论 GET/POST 都不重试。结果不明确时返回 `EXPORT_SUBMIT_UNKNOWN` 并停止本批后续仓库。
- 队列空 `path` 仅表示仍在处理：超时返回 `EXPORT_POLL_TIMEOUT`；结构异常、无法可靠匹配或状态不可确认返回 `EXPORT_STATUS_UNKNOWN`。队列 GET 网络故障最多重试一次并退避 3 秒，查询类 5xx 最多一次并退避 5 秒。
- 下载 GET 仅对网络故障或 5xx 最多重试一次并退避 5 秒；401/403 不重试，429 不重试并写入跨进程 15 分钟 cooldown。冷却期间在验证码和登录前即拒绝所有真实调用。
- 四仓局部轮询/下载/文件校验失败时保留已有成功文件并继续后仓；认证、风控、队列结构未知或提交结果不明确时停止整批，当前仓失败，后续仓标记 `skipped`。
- 文件下载只接受雅仓 OSS HTTPS 白名单，并校验大小、MD5（存在时）和 XLSX 文件头；当前已确认的库存动销协议另外校验固定表头和单仓数据。
- 同一份已校验的四仓库存动销原始文件在本地投影为两类交付物：每仓一份 7/15/30 文件和每仓一份日度 90 天文件。两条命令共享短期原始文件缓存，连续执行时不会重复提交生产导出。
- 业务展示名与 Windows 安全文件名由集中映射生成。库存列表使用已确认的 `stockWarehouse/export` 当前库存协议，按四仓分别导出并验证固定 18 列；接口无日期参数，不支持补导历史月末。入库/上架时间使用已确认的 `sku/export` 在售资料协议，整体导出一份固定 11 列 XLSX，并将原生“创建时间”作为业务确认的入库/上架时间。

`test_dataset_registry.py` 的模块白名单同步加入 `yacang`，使新增产物分区成为显式架构决策。
