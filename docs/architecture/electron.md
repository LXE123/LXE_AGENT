# Electron 模块介绍

总览：[架构简介](README.md) · 审查入口：[PR 审查规范（LXE_AGENT ）](../pr-review.md)

Electron 模块是面向用户的应用层，也是 LXE_AGENT 的用户交互入口。它提供统一的交互界面，通过 JSON-RPC 2.0 对接 agentcli 的 Agent 能力，通过 lxeskillCLI 暴露的命令调用业务能力。

对话入口将用户消息交给 agentcli，由模型推进任务；工作台和设置等明确的功能入口，由 Electron 调用相应应用服务或 lxeskillCLI 暴露的命令。Gateway 负责消息接入、会话绑定、任务调度和结果交付。

## 1. 界面与交互模块

负责展示应用状态，接收用户操作。

- 提供对话、工作台、设置、统计等界面。
- 展示消息、执行进度、工具调用和文件结果。
- 将用户操作转换为应用请求，并展示处理结果。

## 2. 桌面通信模块

负责界面与主进程之间的通信。

- 通过 Preload 向界面提供明确的调用接口。
- 使用 Electron IPC 传递请求、响应和事件。
- 校验调用来源与参数，将请求交给对应的主进程服务处理。

## 3. Gateway 接入与任务调度模块

负责把不同入口的请求交给 agentcli，并将执行结果交付给对应的接入方。

- 接入桌面对话、飞书等渠道的消息与操作。
- 管理接入侧的会话绑定、任务排队、取消和执行中的补充消息。
- 将 agentcli 返回的事件、消息和文件交付信息路由到对应渠道。

## 4. 能力对接与运行管理模块

负责连接 agentcli 和 lxeskillCLI，将它们的能力接入桌面应用。

- 启动和管理 agentcli 进程，通过 JSON-RPC 2.0 交换请求、响应和事件。
- Electron 通过 lxeskillCLI 暴露的命令调用业务能力，例如工作台操作、业务设置和媒体处理。
- 为子进程配置工作目录、环境变量和数据路径。
- 检查运行环境与依赖状态，处理进程退出、调用错误和诊断信息。

## 5. 配置与应用数据模块

负责桌面应用自身的配置与数据管理。

- 管理应用设置、模型配置、凭据和界面偏好。
- 管理桌面侧的缓存、日志等应用数据。

模块之间的数据归属见 [架构简介#3. 数据归属](README.md#3-数据归属)。

## 6. 文件与桌面系统集成模块

负责侧边栏中的文件查看和手动操作，并连接操作系统能力。

### 侧边栏与文件预览

- 展示工作区文件树，管理文件、终端和浏览器标签页。
- 预览文本、Markdown、HTML、图片、PDF，以及 Word、PPT、Excel 文件。
- 按会话保存标签页、布局和文件阅读位置。

不同文件使用不同的预览方式：

- **Word、PPT**：通过 LibreOffice Kit 的 Node API 转换为 PDF，再使用 PDF.js 展示；PDF 文件直接展示。
- **Excel**：使用 FortuneSheet 展示表格数据，当前为只读预览，不在预览时重新计算公式。

共享 Office 引擎的其他用途见 [架构简介#共享 Office 引擎](README.md#共享-office-引擎)。

### 文件服务

主进程的文件服务负责解析工作区、附件和产物等文件引用，校验访问路径，读取文件，并处理预览转换与缓存。

Office 预览转换使用临时副本，生成的 PDF 存入预览缓存，不覆盖原文件；文件服务处理转换取消、超时、错误和临时资源清理。

### 桌面系统集成

- 管理窗口、托盘、系统菜单和剪贴板。
- 提供文件选择、附件处理和外部应用打开能力。
- 提供用户手动操作的终端和浏览器，并管理相关资源的创建与关闭。

这里的手动终端和浏览器服务于用户操作；模型使用的 `exec` 等工具由 agentcli 提供。

## 7. 云端接入模块

负责桌面应用与云端服务之间的连接。

- 处理设备注册、激活和身份信息。
- 获取并同步云端提供的模型配置与应用权限。
- 管理所需的网络连接，并向用户展示连接状态和异常。

## 8. 应用更新模块

负责桌面应用的版本更新。

- 检查新版本，下载并校验更新包。
- 展示更新进度、失败原因和重试状态。
- 安装前协调正在执行的任务和桌面资源，完成更新与重启。
