# lxeskillCLI 模块介绍

总览：[架构简介](README.md) · 审查入口：[PR 审查规范（LXE_AGENT ）](../pr-review.md)

lxeskillCLI 是项目维护的独立业务命令行工具，使用 Python 实现，通过 `lxeskill` 命令入口暴露业务命令。用户、agentcli、Electron 或其他程序均可通过这些命令使用其能力。

它按次启动，执行命令并返回结果，自行管理业务配置、认证信息和产出文件。

## 1. CLI 入口与命令契约模块

负责对外提供统一、可发现的命令接口：

- 解析命令和输入参数，将请求分发到对应处理模块。
- 通过命令目录（Catalog）定义命令名称、参数结构、技能归属和产物声明。
- 提供 `list`、`describe`、`doctor` 等发现与检查命令。
- 区分业务命令、浏览器命令、维护命令和内部命令。

`catalog.json` 是 lxeskillCLI 内部维护的命令目录。调用方通过 `list`、`describe` 等 CLI 接口查询所需信息。

部分命令用于 Electron 等应用程序的功能集成，不面向 AI 的常规任务调用，因此在命令目录中标记为 `internal`，默认不出现在 `list` 结果中。Electron 等调用方仍通过 lxeskillCLI 暴露的命令使用相应能力。

`internal` 表示命令用途与默认可见性，本身不构成权限限制。

lxeskillCLI 的公开接口由命令、参数、输出格式和退出码组成，调用方依据这些约定使用其能力。

## 2. 业务执行模块

负责具体业务流程、参数校验和计算规则，例如：

- FBA 发货、装箱及相关单据处理。
- 越南备货计算与参数管理。
- ERP 报表导出与数据整理。
- 图片和视频的 AI 人物标签处理。

命令处理层接收标准化参数，再调用对应业务实现。

多数命令实现位于 `python/lxeskill_cli/services/commands/`，并按业务领域组织。

## 3. 外部系统与认证模块

负责与业务系统通信，以及相关认证信息的获取和使用：

- 对接马帮、雅仓、上马等外部系统。
- 构造接口请求，处理分页、下载和外部响应。
- 在业务命令执行时按需获取、刷新和使用 Cookie 等认证信息。
- 识别登录失效、权限不足及外部服务错误。

例如，马帮登录态由 lxeskillCLI 的相关业务实现按需维护，无需 agentcli 提前维护。

## 4. 浏览器自动化模块

负责通过浏览器完成业务操作：

- 管理紫鸟店铺浏览器的打开、状态查询和关闭。
- 获取页面快照、截图，执行导航、点击、输入和滚动。
- 执行亚马逊后台等页面业务流程。

紫鸟页面自动化使用 `SeleniumRunner`，并按浏览器 `core_version` 配对 chromedriver。浏览器实时状态以外部客户端和实际浏览器为准。

## 5. 业务数据与文件模块

负责业务执行所需的数据和文件：

- 管理 lxeskillCLI 自身的业务数据库、配置和可重建缓存。
- 管理模板、SKU 映射表等长期输入资料。
- 读取、校验、生成和重算 Excel 等文件。
- 管理产物目录、输入快照和文件路径。

需要 Office 引擎能力时，业务实现通过内部适配调用 LibreOffice Kit CLI。例如，越南备货流程使用它重算 Excel 文件，再由业务实现检查结果。内部适配负责超时和进程清理；业务规则、输入输出文件和结果校验由 lxeskillCLI 管理。

共享引擎也供 Electron 文件预览和模型通过终端命令使用，见 [架构简介#共享 Office 引擎](README.md#共享-office-引擎)。

模块之间的数据归属见 [架构简介#3. 数据归属](README.md#3-数据归属)。

## 6. 结果与错误输出模块

负责将执行结果统一返回给调用方：

- 通过 stdout 输出结构化 JSON；多条记录使用 JSONL 分帧。
- 区分执行进度、最终结果、错误和产物信息。
- 使用退出码表达命令执行状态。
- 保留经过必要脱敏和显式截断的实际错误。
- 将诊断日志与标准结果输出分开。

lxeskillCLI 返回结果和文件信息，后续如何展示或交付由调用方负责。
