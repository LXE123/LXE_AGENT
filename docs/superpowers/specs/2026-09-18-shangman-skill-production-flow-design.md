# 智慧印尼导出 Skill 与生产开关规格

## 目标

确认自然语言商品导出请求能够被唯一 Skill 识别，并提供与现有桌面设置一致的持久化生产开关；在不连接真实 ERP 的前提下，用本地替身验证从意图到导出产物的流程通路。

## 范围

1. 检查并补强 `shangman-goods-export-workflow-map` 的 manifest、catalog、owner skill 和自然语言入口测试。
2. 在桌面“智慧印尼”设置中增加持久化生产 API 开关。开关默认关闭，状态保存在非敏感配置中，环境变量由该状态派生。
3. 增加本地流程测试，覆盖预览、生产门禁、验证码暂停/继续和 XLSX 产物校验；禁止真实 ERP 请求。
4. 保留当前 Dashboard/Electron 开发端口对齐修复。

## 非目标

- 不启用真实生产 API，不保存或展示明文密码、验证码。
- 不改变现有 `goods-export` 公共命令和自然语言语义。
- 不把截图中的智汇 TMS 文案或字段复制到智慧印尼集成。

## 验收标准

- Skill catalog 能发现该 Skill，`amazon_replenish` 类型和 owner skill 均能通过现有识别契约；自然语言商品导出测试能命中唯一入口。
- 桌面设置显示两列账号字段、生产 API 开关和清除按钮；开关状态可保存、重启后恢复，默认关闭，清除后关闭。
- 生产关闭时流程返回 `production_gate_required`；打开后本地替身流程能经历验证码输入，再生成并校验 XLSX。
- 定向测试、类型检查和 `git diff --check` 有真实结果；不声称完成真实 ERP 联调。
