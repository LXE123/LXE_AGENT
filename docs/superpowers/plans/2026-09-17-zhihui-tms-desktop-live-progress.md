# 智汇 TMS Desktop 实时进度实施计划

## 目标

智汇商品导出仍在运行时，Desktop 当前会话的工具卡片实时显示登录、分页、导出、下载和合并阶段。保持原有终态、错误、附件交付和模型可读输出。

## 调用链

`lxeskill` 已输出受控 JSONL → Agent 的 `exec` stdout 读取器识别智汇进度 → Agent CLI 发布类型化事件 → Gateway 更新当前回合的工具卡片 → Desktop Renderer 展示进度文字。

## 任务

1. 为智汇命令新增严格的增量 JSONL 解析器，只接受现有七种阶段及安全数字字段，输出固定格式的中文进度文字。原始行、账号、Token、URL 不进入事件。测试跨块、伪造字段、非智汇命令与过长行。
2. 在现有进程输出模块加可选回调，按会话、回合、工具调用和 exec ID 关联进度。回调异常不得中断业务命令。
3. 在 Desktop 协议加入受控进度事件并更新版本；Agent CLI 发送，Gateway 仅修改匹配且仍在运行的工具卡片，并处理进度先于卡片到达的情况。保留原有 `background_task.changed` 终态语义。
4. Renderer 在运行中的工具卡片摘要展示进度；结果区域仍展示详情。定向测试验证进度、终态覆盖和多会话隔离。
5. 运行相关 Bun 测试和类型检查、智汇 Python 定向测试、`git diff --check`、`git status`，检查敏感信息与无关改动；写交付文档。向用户列出精确文件及提交信息申请 `git add` / `git commit` 批准。

## 约束

- 仅智汇 TMS，不调用真实接口或使用真实凭据。
- 不改变限频、重试、风控停止策略和附件结果。
- 不把 CLI 原始 stdout 当成 Desktop 进度事件；仅通过白名单解析器输出固定文字。
- 本轮不执行任何 Git 状态修改命令，除非用户对精确文件与提交信息明确批准。
