# 业务命令调用统计

lxeskillCLI 在有归属 Skill 的业务命令结束时，向自己的 `lxeskill.sqlite3` 写一条记录。记录包括随机事件 ID、命令目录里声明的命令路径、全部归属 Skill、是否成功、耗时和 UTC 开始时间。例如 `lxeskill replenish store resolve --store-name 示例店铺` 只记录命令名 `replenish store resolve`。参数名、参数值和调用方都不会写入统计。进入命令后发生的参数错误和业务异常也计一次。

`list`、`describe`、帮助、`doctor`、`datasets list` 和云端自检不计数。桌面使用的设置、资产列表和媒体命令没有归属 Skill，也不计数。agentcli 按回合统计 Skill 目录使用，两套统计各自采集、各自上传。业务命令调用次数在服务端看板查看。

配置有效的 `LXE_DATA_SERVER_URL` 后，每次写入都会尝试上传积压记录。CLI 在本进程中按时间从早到晚发送，每批最多 200 条，每次最多三批，共用约两秒的等待预算。服务端按事件 ID 去重。只有 HTTP 200 确认的新增数和重复数之和等于批次大小，CLI 才标记这批记录已上传。

上传失败时，命令仍输出原来的结果并返回原退出码。十分钟后，下一个有归属 Skill 的命令会再次尝试。缺少有效地址时只保存在本地。待传最多保留最近 5000 条，已确认的记录在上传满 30 天后随下一次写入清理。
