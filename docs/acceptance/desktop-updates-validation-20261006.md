使用实际 Electron **43.7.0**、锁定的 electron-updater **6.6.2**，通过本机 HTTP 夹具提供两个真实 NSIS 安装包及 blockmap。每次成功下载都对合成文件执行完整 SHA-512 校验，必须与目标完整包一致。

| --- | ---: | ---: | --- |
| 正常差分 | 881,670 | 1,567,597 | 7 次单区间 Range，无完整包请求 |
| 缓存删除 | 327,898,715 | 327,898,715 | 完整下载成功 |

原生提权启动使用无副作用的 Node 夹具，验证确认启动成功后才返回，并保留中文、空格参数。下载夹具每次先移除旧成功标记，避免旧文件造成假通过。
