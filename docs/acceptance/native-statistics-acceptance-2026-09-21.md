## 历史归属与后续发布

上述表格保留最初迁移的验证记录。后续核实发现，Codex 0.154.0 已内置跨源重定向限制；最初把允许同源路径跳转误当成可以访问任意服务器的证据，因此增加了不必要的转发层。`e45b335` 已撤除该层，保留设备鉴权、飞书用户授权、工具限制和代理绕过。纠正后类型检查、构建通过，全量 647 passed、3 skipped；实际 SDK 隔离测试验证直连和同源跳转均完成 MCP 调用，跨源 307/308 的目标收到 0 次请求，观察到的请求没有 Authorization/Cookie。服务器与桌面代码不需要为此修改，Mac mini 尚未发布。

生产只做了健康/权限查询和历史归属汇总读取，没有写入模拟统计、停用设备或收权。已发现独立网关 631 条历史统计均未验证设备归属。旧版本可继续运行；未来更新 Mac mini 前，必须核实它的持久化 machine_id 并按服务器维护命令登记归属，然后预览/应用网关配置迁移。不能自动猜测或新建 ID 绕过。

旧业务 Token 申请/刷新和旧服务端鉴权分支本轮保留。当前结果是迁移后的日常调用不再依赖业务 Token，不代表所有旧凭据已经删除。
