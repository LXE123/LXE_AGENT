# 聊天展示控制器验收

从仓库根运行：

```sh
bun apps/dashboard/test/features/sessions/display-fixture-server.ts
```

打开 `http://127.0.0.1:5199/test/features/sessions/display-fixture.html`。
所有数据都来自内存 fixture，不调用模型、Gateway 或生产会话。

这个页面使用生产的 `SessionDetailView`、`useSessionConversationQuery`、
`useConversationActivityQuery`、`ConversationDisplayController` 和 `sendConversationMessage`。
仅替换 `DashboardTransport`；发送时的 activity、历史确认和晚到响应均经过实际 Query 缓存。
没有另造展示 rows。

依次点击：

1. **Run send scenarios**：空历史先完成，随后发送纯文本、图片、仅附件和新会话；检查
   DOM 气泡身份不变、失败/取消即时显示、附件晚确认、切换会话后晚到响应不抢回页面。
2. **Run 1000 group history**：完整向前和向后重新加载 1,000 组，检查缓存裁剪、可见项数量、
   分页锚点、后台最新页不抢滚动位置，以及分页失败后保留窗口。
3. **Run height and races**（紧接上一项）：图片高度增长、整体过程折叠、工具独立展开、虚拟
   卸载重挂载、分页过程中切换会话，以及单个超大组保留。
4. **Run cache budget**：20 MiB 的普通历史页会整组裁剪，Query 也只持有裁剪后的页；
   17 MiB 的单组按例外保留，切换会话释放旧 Query 页。
5. **Run answer footer**：空提示无卡片背景和图标；多段最终正文只有一个底部操作栏，
   文件晚到后位于正文与操作栏之间，正文及操作栏 DOM 身份不变，过程展开不改变顺序。
   通过临时 clipboard 适配器检查实际复制按钮传出的内容，仅包含全部最终正文。
   同时检查正文到文件标题的间距不超过 9px，操作栏默认隐藏，悬停回答正文、文件或
   操作栏时显示，离开或移到用户消息时隐藏；键盘聚焦仍能显示。
6. **Run tool lifecycle**：工具只有调用时显示待执行图标；开始后保持转圈，跨越四次
   历史刷新和多个动画周期。检查五种图标的悬停提示、右侧定位、稳定行身份和高度，
   后台运行不随 turn 结束而停止，同序号完成更新生效，迟到开始事件不回退状态。
7. **Run session reentry**：历史先返回和实时状态先返回；冷加载、切回命中实时缓存、
   从首页返回同一个会话命中历史缓存。上一轮长回答之后，运行中的正文和图片继续增高，
   稳定后距底部不超过 2px，当前输出可见。加载期间主动上滚保留阅读锚点，
   点击“跳到最新”恢复跟随；阅读导航键和滚动条按下立即取消跟随，重复点击当前会话
   不重置阅读位置。还覆盖初次加载中主动阅读，以及阅读窗口脱离最新页后从首页返回。
   会话进入使用与主页面相同的 `useConversationEntry`。

工具运行状态使用生命周期，正文刷新优先级不决定工具是否完成。历史缺少结果时不判成功；
旧 exec/wait 的运行观察只解析执行器控制头，不把 stdout 当状态，也不把过去的后台运行
记录当成当前进程存活证明。工具终态依据只保留在当前阅读窗口，历史确认结果后释放实时
载荷，窗口淘汰或会话切换时一并释放。

结果直接显示在页面顶部。图片测试在已挂载的 Markdown 中加入本地 SVG 图片并改变其高度，
触发实际 ResizeObserver 测量；锚点在布局稳定后读回，不以累计高度差代替行身份。
fixture 的全量数据是模拟服务端数据，不计入被测应用的常驻历史载荷。

## 状态职责

- 控制器拥有消息交接、加载状态、窗口连续性及本地更新代次。
- Query 执行请求、去重分页和缓存最新页；过期请求无法提交给控制器。
- 虚拟列表负责测量与滚动，向控制器报告跟随状态和可见组。
- `has_previous` / `has_next` 只描述分页；实时行是否参与当前窗口由连续性决定。
- 发送和“跳到最新”共用一个入口；手动发送重连尾部，后台更新保留阅读锚点。
- 切回会话也复用“跳到最新”；跟随意图由明确的阅读操作取消，布局和程序滚动不取消。
  历史分页测试先发送上滚意图，再设置目标位置，区别于程序自动对齐。

## 浏览器实测（2026-09-07）

417 × 750 视口：1,000 组双向读取，合计缓存最多 60 组，最多挂载 15 项。
分页裁剪、图片增长、过程展开在高度稳定后测得锚点偏差均为 0px。
工具展开在整体折叠和虚拟重挂载后保持。

普通大页的 Query 消息载荷为 14,683,362 字节（7 组），小于 16 MiB；
单个超大组保留 17,826,246 字节。预算限定历史消息载荷，并非浏览器进程总内存上限。

1280 × 900 桌面视口再次通过发送交接及 1,000 组双向读取：最多缓存 60 组、
最多挂载 19 项，稳定后的分页锚点偏差为 0px。

加入独立回答底部项后，1280 × 900 回归最多挂载 23 项，缓存仍最多 60 组；
分页、图片增长和过程展开的锚点偏差均为 0px。空提示、晚到文件顺序、复制内容、
用户气泡及附件交接均通过；工具展开状态在整体折叠和虚拟重挂载后仍保留。

收紧回答间距并恢复操作栏悬停显示后，正文末尾到文件标题实测为 8.20px。
1280 × 900 的 1,000 组回归最多挂载 25 项，缓存最多 60 组，分页锚点偏差 0px。

工具状态修复后：五种图标、跨四次刷新持续旋转、同序号后台完成、迟到事件保护通过；
工具行身份和摘要高度不变。1,000 组回归仍最多挂载 25 项、缓存 60 组，分页、
图片增高和过程展开的锚点偏差均为 0px，工具展开状态在虚拟卸载后恢复。

切回滚动修复：1280 × 900 Electron 窗口中，历史与实时状态的两种返回顺序、
冷加载、缓存命中、从首页返回及脱离最新页后返回均通过。正文和图片增高后距底部
不超过 2px，主动阅读的锚点偏差不超过 2px。1,000 组分页最多挂载 23 项、
缓存 60 组，分页、图片和过程展开的锚点偏差均为 0px。
原生滚轮、PageUp、滚动条拖动均立即取消跟随；点击“跳到最新”后实测距底部 0px。
同一切回用例使用修复前的列表和进入行为时，复现正文增长后距底部 106.5px 的失败。
