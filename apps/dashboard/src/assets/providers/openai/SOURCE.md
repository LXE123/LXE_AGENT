# OpenAI provider icon

The shared provider mark uses the original 24 × 24 path and even-odd fill from
the [Lobe Icons OpenAI SVG](https://github.com/lobehub/lobe-icons/blob/ea434b96e75813517b377825e01c0df61dee8836/packages/static-svg/icons/openai.svg).
The mark uses the theme foreground color and is bundled with the Dashboard.
